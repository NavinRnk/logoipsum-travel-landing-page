# LogoIpsum Travel Landing Page

This is a travel landing page built using React, TypeScript, Vite, and SCSS.

## How to Run

1. Install Node.js.
2. Open the project folder in the terminal.
3. Run `npm install`.
4. Run `npm run dev` to see the output in the browser.

## Folder Structure

- `src/assets/images` – Contains the images used in the project.
- `src/components` – Contains reusable components like Header, Footer, and Carousel.
- `src/pages` – Contains the Home page.
- `src/scss` – Contains the SCSS files for styling.
- `src/vite-env.d.ts` – Contains Vite type declarations.

## Technologies Used

- React
- TypeScript
- Vite
- SCSS
